## 🚑 Featured Project: Aerixon

**An emergency dispatch backend that never double-assigns an ambulance, even under concurrent load.**

`Node.js` `Express.js` `MongoDB` `2dsphere Geospatial` `JWT` `RBAC`

- 🔒 Fixed a race condition with **atomic, conditional MongoDB updates**: 3 allocations became exactly 1 across 50 concurrent requests
- ♻️ **Idempotent, failure-safe APIs** with retry and exponential backoff
- 📍 Real-time **nearest-ambulance discovery** using 2dsphere queries
- 📈 Custom Node.js load-testing framework (up to 500 simultaneous requests, p95/p99 latency)
- 🔐 JWT auth, RBAC, audit logging and health endpoints

🔗 [Repository](https://github.com/Ujjwalkumar6200/aerixon-backend) &nbsp;|&nbsp; 🟢 [Live health check](https://aerixon-backend.onrender.com/health)
