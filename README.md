### 🚑 Aerixon — Emergency Dispatch Backend System

**Node.js · Express.js · MongoDB · Geospatial Indexing · JWT**

A fault-tolerant backend system designed to safely allocate ambulances during concurrent emergency requests.

🔗 **Repository:**  
https://github.com/Ujjwalkumar6200/aerixon-backend

### Key Engineering Highlights

- 🏗️ Designed the **High-Level Architecture (HLD)** for a highly available emergency dispatch service
- ⚡ Handled **concurrent emergency requests** and race conditions
- 🔒 Used **atomic MongoDB operations** to prevent double ambulance assignment
- 📍 Implemented **2dsphere geospatial queries** for location-based ambulance allocation
- 🔁 Added **retry mechanisms with exponential backoff**
- 🔐 Implemented **JWT authentication and Role-Based Access Control (RBAC)**
- ♻️ Designed **idempotent REST APIs**
- 🔄 Implemented failure-safe **state transitions**
- 📝 Added audit logging and health/diagnostic endpoints

**Live Health Check:**
